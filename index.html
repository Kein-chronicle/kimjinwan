AI 운영 체계 — 6원칙How I operate AI — 6 principles

01
세션 검토Session review

세션마다 상태·합의·용어를 먼저 명시적으로 확인한다. '당연히 알겠지'가 가장 비싼 가정이다.Re-read state, agreements and terms every session — "they'll just know" is the costliest assumption.

02
하네스 구축Build the harness

용어 사전·영역 한정·완료 채점표를 먼저 세운다. 완료가 의견이 아닌 확인이 되도록.Set up a glossary, scope fences and a completion rubric first — so "done" is verified, not opinion.

03
실행Execute

결정은 사람이, 수행은 AI에게. 방향이 정해지면 질문 없이 지시한다.Humans decide, AI executes. Once the direction is set, I instruct — I don't ask.

04
다층 검증Multi-layer verify

AI=로직, 사람=비주얼. lint/build/test → 실제 화면 → 시각·수동까지 충돌을 메운다.AI judges logic, I judge the visual — verify across lint/build/test, the live screen and a human look.

05
정리Close out

툴·세션이 바뀌어도 같은 상태로 시작하게. 커밋 히스토리·핸드오프 문서로 닫는다.Close so any tool/session resumes identically — commit history and a handoff doc are the memory that survives.

06
이월Carry over

잘 된 과정은 스킬·도구로 이월. 쌓일수록 다음 프로젝트가 검증된 자산 위에서 시작한다.Carry wins forward as skills and tools — each project starts on proven assets. It compounds.

↩ 이월(06)이 다음 세션 검토(01)로 이어지는 사이클 — 쓸수록 AI가 나에게 맞춰지고, 새 프로젝트도 검증된 자산 위에서 시작합니다.↩ Carry-over (06) feeds the next session review (01) — the more I run it, the more AI fits me, and new projects start on proven assets.
