Forge

요구사항 정의에서 디자인·화면설계·개발 보조·익스포트까지 하나의 흐름으로 잇도록 직접 만든 웹서비스 제작 도구.A web-service production tool I built to connect requirements, design, screen specs, development assistance and export in one flow.

서비스 열기Open the service

주요 기능Main features

  • 8단계를 한 흐름으로Eight stages in one flow 요구사항 정의 → 디자인 가이드 → IA · 키스크린 → 전체 목업 → 기획서 → UI 디자인 → 개발 보조 → 프로젝트 익스포트까지 단계마다 결과를 확인하며 이어 갑니다.Requirements, design guide, IA and key screens, full mockup, spec, UI design, dev assistance and export, each confirmed before the next.
  • 빠진 정보는 질문과 추천안으로Gaps become questions and suggestions 여섯 줄짜리 서술에서 시작해도 빠진 정보는 질문과 추천안으로, 확인이 필요한 건 웹 리서치로 채웁니다.Start from a six-line description; missing details come back as questions with suggested answers, and web research covers what needs checking.
  • 디자인 가이드 편집기Design guide editor 요구사항에 맞는 가이드를 추천받고 색 · 글꼴 · 모서리 · 컴포넌트를 고치며 바로 미리 봅니다.Get a recommended guide, tweak colors, fonts, corners and components, and preview the result right away.
  • 실제 링크로 눌러 보는 목업A mock site you can click 핵심 화면 5개로 컨셉을 먼저 확정하고, 나머지 화면은 실제 링크로 눌러 보며 고칩니다.Lock the concept with five key screens first, then click through the rest with real links and refine.
  • 번호 마커 화면설계서Numbered-marker screen spec 목업을 실제 해상도로 재서 번호 마커와 디스크립션이 붙은 화면설계서를 씁니다.The mockup is measured at real resolution to produce a screen spec with numbered markers and descriptions.
  • 개발 에이전트에게 바로 넘기는 세트A set ready for a coding agent 기획 · 디자인 · 개발 산출물을 골라, 로컬 개발 에이전트가 추가 설명 없이 완성할 수 있는 프로젝트 세트로 묶습니다.Pick the planning, design and dev outputs and bundle them so a local coding agent can finish the project without extra explanation.

이런 분께 맞습니다Who it is for

  • 고객 요구사항서를 받아 제안 · 기획을 빠르게 정리해야 하는 PM · 기획자 · 영업PMs, planners and sales people who must turn a client requirements doc into a plan fast
  • 요구사항 → 디자인 → 화면설계 → 개발까지 문서가 끊기지 않았으면 하는 소규모 팀Small teams who want requirements, design, screen specs and development notes to stay connected
  • 개발 에이전트(Claude Code · Codex)에 넘길 프로젝트 세트가 필요한 1인 개발자Solo developers who need a project set to hand to a coding agent
  • 목업 사이트를 먼저 눌러 보며 컨셉을 확정하고 싶은 디자이너Designers who want to confirm the concept by clicking through a mock site first

사용 방법How to use

  1. 가입하고(이메일 · Google · Apple) 내 PC에 Forge Agent를 한 번 연결합니다. 명령 한 줄이거나 설치 파일 더블클릭입니다.Sign up and connect the Forge Agent to your PC once, with one command or a double-clicked installer.
  2. 프로젝트를 만들고 요구사항을 적거나 올립니다.Create a project and write or upload your requirements.
  3. 단계마다 결과를 확인하고 대화로 고치며 8단계를 차례로 진행합니다.Walk through the eight stages, confirming each result and refining it in chat.
  4. 원하는 산출물을 골라 PDF · 프로젝트 세트로 내려받습니다.Choose the outputs and download them as PDFs or a project set.

알아둘 점Good to know

  • AI 판단은 서버가 아니라 내 PC의 Claude Code · Codex(내 구독)가 합니다. 서비스 서버에는 모델이 없습니다.The AI work runs on your own PC through Claude Code or Codex (your subscription). The service server has no model.
  • 데모 프로젝트(요구사항 → 기획서)는 Sonnet으로 약 15분 걸렸습니다. 프로젝트 전체를 자주 돌린다면 Claude Max 5x 이상 또는 ChatGPT Pro 이상을 권장합니다.The demo project (requirements to spec) took about 15 minutes with Sonnet. For frequent full runs a Claude Max 5x or ChatGPT Pro plan is recommended.
  • Agent는 파일 · 셸 · MCP 도구를 끈 채 빈 임시 폴더에서 모델만 실행하고, 서버는 명령이나 경로를 보낼 수 없습니다.The agent runs the model alone in an empty temp folder with files, shell and MCP tools off; the server cannot send commands or paths.
  • 팀은 계정 없이 프로젝트 코드와 비밀번호로 공유합니다. 편집은 한 번에 한 사람입니다.Teams share by project code and password without accounts. One person edits at a time.
