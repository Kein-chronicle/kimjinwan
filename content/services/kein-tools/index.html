Kein Tools

계산기부터 PDF·이미지 처리까지, 가입과 업로드 없이 기기 안에서 처리하는 실용 웹 도구 모음. 웹 도구 공장에서 한 번에 하나씩 만들어 공개하고, 도구마다 규칙과 한계를 함께 적었습니다.A collection of practical web tools, from calculators to PDF and image utilities, processed on your device with no sign-up or upload. The web tools factory builds them one at a time, and each tool lists its rules and limits.

서비스 열기Open the service

주요 기능Main features

  • 가입과 업로드 없이No sign-up, no upload 입력값과 파일을 가능한 한 사용자의 기기 안에서 처리합니다.Inputs and files are processed on your device wherever possible.
  • 분야별 도구Tools by category 이미지 · PDF · QR · 게임 · 생활/학습 · 업무로 나눠 검색하고 거를 수 있습니다.Search and filter across image, PDF, QR, game, life/study and work categories.
  • 업무용 개발 도구Work and dev utilities JSON 포매터 · 검증기, 중복 줄 제거기, 텍스트 비교기, CSV ↔ JSON 변환기 같은 도구가 있습니다.Includes a JSON formatter/validator, duplicate-line remover, text diff and CSV↔JSON converter.
  • 생활 계산기Everyday calculators 단가 비교, 할인율, 더치페이 정산(부가세 · 봉사료 포함), 토너먼트 대진표, 글자 수 · 읽기 시간 등을 계산합니다.Unit price comparison, discounts, bill splitting with VAT and service charge, tournament brackets, character counts and reading time.
  • 규칙과 한계를 함께Rules and limits included 각 도구에 사용 규칙과 한계를 함께 적었고, 사용법 글은 블로그에 정리합니다.Every tool states its rules and limits, and how-to articles live in the journal.
  • 한 번에 하나씩 계속 추가Added one at a time 웹 도구 공장에서 한 번에 하나씩 만들어 공개합니다.The web tools factory builds and publishes them one at a time.

이런 분께 맞습니다Who it is for

  • PDF 합치기 · 이미지 변환처럼 파일을 서버에 올리기 싫은 일을 처리하려는 사람People handling PDF or image tasks who do not want to upload files to a server
  • 단가 비교 · 할인율 · 더치페이 정산 같은 생활 계산을 빠르게 하고 싶은 사용자Users who want quick everyday calculations such as unit price, discounts and bill splitting
  • JSON · CSV · 텍스트 비교 같은 업무용 작은 도구가 필요한 개발자 · 사무직Developers and office workers needing small utilities for JSON, CSV or text diff
  • 도구마다 규칙과 한계가 적혀 있어 결과를 믿고 쓰고 싶은 사용자Users who want to trust results because every tool lists its rules and limits

사용 방법How to use

  1. 검색창이나 분야 칩으로 도구를 찾습니다.Find a tool with search or category chips.
  2. 도구 페이지에서 입력하거나 파일을 고릅니다.Enter values or choose a file on the tool page.
  3. 결과를 확인하고 필요하면 복사 · 저장합니다.Check the result and copy or save it.

알아둘 점Good to know

  • 도구 수는 계속 늘어납니다. 계산 결과는 참고용이며, 중요한 판단 전에는 한계 안내를 확인하세요.The tool count keeps growing. Results are for reference; check each tool's limits before important decisions.
