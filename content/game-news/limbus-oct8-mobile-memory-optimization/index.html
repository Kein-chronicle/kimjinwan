림버스 10월 8일 모바일 최적화 예고 — 메모리 15% 감소는 어떤 조건의 수치인가

기록일 2026. 10. 3.

10월 3일 루틴에서 확인한 기록이며 실제 공개일은 발행 시각 기준이다.

이 글의 목적

10장 3부에서 앱이 종료되는 모바일 이용자가 최적화 예정일과 수치의 적용 범위를 확인하게 한다.

핵심 내용

개발사 예고의 최대 약 15%·300MB 감소는 앱이 사용할 수 있는 RAM 4GB의 내부 iOS 시험 기준이며, 모든 4GB 기기에서 종료 문제가 사라진다는 보장은 아니다.

읽고 나서

10월 8일 12시 이후 실제 업데이트 공지를 확인하고, 문제가 이어지면 기기 모델·발생 구간·스크린샷을 함께 고객센터에 전달한다.

목차
  • 먼저 답하면
  • 적용 예정은 10월 8일 12시
  • 15%를 내 기기의 결과로 읽지 않기
  • 업데이트 뒤에도 반복 종료된다면

먼저 답하면

10월 8일 최적화는 예고 단계이며, 모든 휴대폰의 튕김 해결을 확정한 공지가 아니다. 림버스 컴퍼니 개발사가 공개한 최대 약 15% 메모리 감소는 내부 시험의 특정 조건에서 나온 수치다.

적용 예정은 10월 8일 12시

10월 2일 밤 공식 예고는 **1.116.2를 2026년 10월 8일 12:00(KST)**에 적용할 예정이라고 안내했다. 이미 설치 가능한 모바일 1.116.1과 난도 설문의 후속이며, 설문에 따른 보스 난도 변경과도 별개다.

대상은 10장 3부의 전투·시각 효과 자원이다. 압축 방식 개선, 특정 연출 자원이 다음 장면에 남는 문제 수정, 불필요한 자원 로딩 제거를 예고했다. 공지상 해당 자원의 해상도는 유지된다.

15%를 내 기기의 결과로 읽지 않기

개발사는 앱이 사용할 수 있는 RAM 4GB의 내부 iOS 시험 기기에서 3부 후반을 연속 플레이할 때 최대 약 15%, 약 300MB 감소를 관찰했다고 밝혔다. Android에도 같은 최적화 과정을 적용할 예정이지만, Android에서 같은 감소율을 측정했다는 뜻은 아니다.

기기 상태와 백그라운드 작업에 따라 결과가 달라질 수 있고, 4GB 기기의 특정 전투에서 앱 종료가 사라진다는 보장도 없다. 이 글은 공식 자료를 읽은 정리이며 기기별 재현 시험은 하지 않았다.

업데이트 뒤에도 반복 종료된다면

적용 후에도 문제가 이어지면 다른 앱을 닫고 다시 시도하는 방법이 안내됐다. 계속 발생할 때는 기기 모델·발생 구간·스크린샷을 고객센터에 전달한다. 숫자 하나로 구매나 기기 교체를 결정하기보다, 실제 배포 공지와 본인 기기의 재현 결과를 확인하는 편이 맞다.

같이 읽을 글

  • 림버스 10월 2일 — 5층 보스 설문 마감과 모바일 1.116.1 확인 순서

    10장 3부 5층 보스 난도 설문은 10월 8일 10시까지다. 모바일 버그 수정 업데이트와 추가 난도 조정 검토를 구분한다.

  • 림버스 10월 1일 핫픽스 — 재접속과 5층 보스 광기 환급 조건

    10월 1일 공식 배포 완료 공지로 보조 아이템 완화와 5층 보스 설명 변경, 10월 8일 광기 환급 대상을 구분한다.

  • 림버스 1.115.0 퀘스트 막힘 — '세이브 복원' 위치와 쓰면 안 되는 경우

    프로젝트문이 9월 24일 1.115.0의 알려진 문제 16건을 공지하고, 같은 날 저녁 핫픽스와 칸토 10 전용 '세이브 복원' 기능을 예고했다. 어디에서 누르는지, 언제 쓰면 안 되는지 공식 원문 기준으로 정리했다.
