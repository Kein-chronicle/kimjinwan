다운로드Download

설명About

제품·서비스·방법을 같은 기준으로 조사해 비교표로 만들 틀을 줘요. 구매·도입 전에 비교 조사를 하는 분.

이런 분께 맞습니다Who it is for

구매·도입 전에 비교 조사를 하는 분.

결과물What you get

비교 기준, 조사할 곳, 비교표, 결정 규칙이 나와요.

쓰는 방법How to use

  1. [내용 복사하기]를 눌러요.
  2. 쓰는 AI 대화창(ChatGPT, Claude 등)을 열고 붙여넣어요.
  3. [대괄호]를 내 상황으로 바꾸고 Enter를 눌러요.

프롬프트 전문Full prompt

전문 접기·펼치기Show / hide the full text
선택지를 같은 기준으로 비교 조사하려고 해.

무엇을 고르나: [예: 팀 협업 도구 3개 중 하나]
후보: [예: A, B, C]
필수 조건과 있으면 좋은 조건: [여기에 적으세요]
예산과 인원: [여기에 적으세요]

만들 것:
1. 비교 기준 10개 이내 (필수 vs 선택으로 구분)
2. 각 기준을 어디서 확인하는지 (공식 가격 페이지, 문서, 시험 사용, 사용자 후기 등)
3. 비교표 양식 (칸에 출처와 확인 날짜도 적게)
4. 결정 규칙 (필수 조건 미달 시 탈락 → 점수 → 직접 시험 사용)
5. 시험 사용 계획과 확인 질문
제품 사양과 가격은 자주 바뀌어 네가 모르니 비워 두고, 내가 채우게 해 줘.

내 AI 환경: [예: 웹 검색 가능 / 파일 업로드 가능 / 붙여넣기만 가능]
- 검색이 안 되면: 내가 붙여넣은 자료만 쓰고, 그렇다고 먼저 말해 줘. 네 기억에서 나온 내용은 "기억 기반(확인 필요)"으로 따로 표시해.
- 검색이 되면: 모든 사실에 출처 주소와 날짜를 붙여 줘. 열어 보지 못한 페이지를 읽은 것처럼 말하지 마.
- 어떤 경우에도 존재가 확인되지 않은 논문·책·통계·링크를 만들어 내지 마.
