설명About

조사 기능이 있는 AI에 맡길 요청서를 같은 틀로 만들어요. 스킬을 지원하는 AI 도구(Claude Code 등)에 한 번 넣어 두면, 같은 일을 시킬 때마다 같은 방식으로 해 줘요.

이런 분께 맞습니다Who it is for

조사를 AI에게 자주 맡기는 분.

결과물What you get

궁금한 것을 말하면 범위·출처 기준·출력 형식이 갖춰진 요청서를 줘요.

쓰는 방법How to use

  1. [파일로 내려받기]로 SKILL.md를 받아요.
  2. 쓰는 AI 도구의 “스킬 폴더”에 deep-research-brief-skill 폴더를 만들고 그 안에 파일을 넣어요. (위치는 도구마다 달라서 쓰는 도구의 스킬 안내를 확인해 주세요.)
  3. 관련된 일을 시키면 AI가 이 설명서대로 일해요.

# 딥리서치 요청서

## 먼저 확인
주제, 쓰임새와 읽을 사람, 지역·기간 범위, 이미 확인한 내용.

## 요청서에 넣을 것
1. 목표와 결정에 쓰이는 방식
2. 범위(포함/제외)와 기준 날짜
3. 우선할 출처와 피할 출처
4. 주장마다 출처 주소와 날짜를 붙이고, 확인하지 못한 주장은 "확인 못 함"으로 구분
5. 엇갈리는 자료는 나란히 제시
6. 출력 형식(요약 → 핵심 발견 → 근거 표 → 불확실한 것 → 더 조사할 것)
7. 모르면 모른다고 말하고 추측으로 채우지 않기

## 규칙
- 완성된 요청서를 복사해서 쓸 수 있는 하나의 글로 준다.

막힐 때If you get stuck

스킬이 작동하지 않으면 폴더 이름이 파일 안의 name(deep-research-brief-skill)과 같은지 확인하세요. 스킬 폴더 위치는 도구마다 달라요. 쓰는 도구의 설명서를 확인해 주세요.
