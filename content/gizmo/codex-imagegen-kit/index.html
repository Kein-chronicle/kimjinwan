Codex 이미지 파이프라인 키트 (투명 PNG·프레임 세트)

Codex 내장 이미지 생성을 터미널에서 불러, 투명 배경 PNG와 애니메이션 프레임을 프로젝트에 바로 쓸 파일로 가져와요

다운로드Download

설명About

Codex 전용 스킬 키트예요. Codex 에 내장된 이미지 생성(image_gen)을 헤드리스(codex exec)로 대신 불러서, 그림을 프로젝트 폴더에 "바로 쓸 수 있는 파일"로 가져와요. Codex 기본 imagegen 스킬이 약한 부분, 즉 투명 배경 PNG, 같은 캐릭터 여러 장, 애니메이션 프레임 세트, 생성 기록을 메워요. 실제로 겪은 문제를 코드로 막아 뒀어요. 투명 배경을 요청하면 투명 대신 체커보드가 그려져 오는 문제는 마젠타 배경으로 받아 지우고, 끝났다고 나오는데 옛 파일이 그대로인 문제는 옛 파일을 치우고 같은 결과면 실패로 보고, 캐릭터가 장마다 달라지는 문제는 첫 장과 직전 장을 첨부해서 만들고, 프레임 크기·바닥선 흔들림은 세트 단위로 맞추고 수치로 검사해요. 목록의 내용은 스킬 본체(SKILL.md)예요. 전체 키트(zip)에는 스크립트 5개(그림 한 장, 프레임 세트, 마무리·키잉, 기하 보정·검사, 공용 코드)와 원리·함정·프롬프트 틀 문서, 설치 안내가 들어 있어요. 받는 파일은 글·자바스크립트·파이썬뿐이고 실행 파일과 이미지는 없어요. OpenAI 의 imagegen 스킬 파일은 포함하지 않았어요. 꼭 알아 두세요. ① Codex 전용이에요. codex 명령이 있고 로그인돼 있어야 하고, 그림은 Codex 가 만들어요. 품질·사용 한도·사용 조건은 내 Codex 요금제와 OpenAI 정책을 따르며 이 키트는 한도를 약속하지 않아요. ② 검사 코드는 깨진 것(빈 프레임·잘림·배경 미제거)만 걸러요. 그림이 좋은지는 사람이 눈으로 확인해야 해요. ③ Codex 업데이트로 내장 도구의 저장 방식이 바뀐 적이 있어요(문서에 기록). ④ 실존 인물·기존 캐릭터·상표를 그리게 하는 건 권리가 있을 때만 하세요. ⑤ 비공식 키트이며 OpenAI 와 관련이 없어요. ⑥ 운영팀이 확인한 것은 macOS + Codex CLI 0.160.1 에서 투명 그림 1장과 2프레임 세트를 실제로 돌려 결과를 눈으로 본 것, 기하 도구 자체 시험, 스캐너 통과까지예요. Windows·Linux·다른 Codex 버전·10장 넘는 세트는 시험하지 않았어요.

이런 분께 맞습니다Who it is for

Codex 를 쓰는 개발자·게임 제작자 중, 만들어진 이미지를 프로젝트에 투명 PNG나 프레임 세트로 넣어야 하는 분. 터미널 명령을 직접 실행할 수 있는 분.

결과물What you get

그림 1장을 투명 배경 PNG 로 만들어 보고, 같은 방법으로 기준 이미지를 물려 같은 캐릭터를 이어 그리거나 걷기·대기 같은 프레임 세트를 칸 크기에 맞춰 뽑을 수 있어요. 만든 프롬프트는 기록 파일에 남아요.

쓰는 방법How to use

  1. [전체 키트(zip) 내려받기]로 zip 을 받아 풀어요. (아래 SHA-256 값과 맞는지 확인할 수 있어요.)
  2. 터미널에서 codex --version 이 나오는지, 로그인돼 있는지 확인하고, 파이썬 Pillow 와 Node.js 18 이상을 준비해요. (INSTALL.md 에 확인 방법이 있어요.)
  3. skills/codex-image-pipeline 폴더를 ~/.codex/skills/ 안에 복사하고 Codex 를 새로 시작해요.
  4. “$codex-image-pipeline 으로 투명 배경 머그컵 이미지를 만들어 줘”라고 말하거나, INSTALL.md 의 확인 명령으로 먼저 계획(--plan)만 보고 한 장 만들어 봐요.

# Codex 이미지 파이프라인

Codex 에 내장된 `image_gen` 도구를 **터미널에서 대신 불러**, 그림을 "쓸 수 있는 파일"로 프로젝트 폴더에 가져온다.
Codex 의 기본 `imagegen` 스킬을 **대체하지 않고 그 위에 얹는다** — 미리보기용 한 장이면 `imagegen` 만으로 충분하다.

## 언제 쓰나 / 언제 안 쓰나

쓴다
- 투명 배경 PNG 가 필요하다 (아이콘·스티커·스프라이트·합성용 컷아웃)
- 같은 캐릭터·스타일로 **여러 장**을 이어서 만들어야 한다 (기준 이미지 물리기)
- 애니메이션 프레임 세트(걷기·대기·공격)를 칸 크기에 맞춰 뽑아야 한다
- "이 그림 어떤 프롬프트로 만들었지?"에 답할 생성 기록이 필요하다

안 쓴다
- 코드·SVG·HTML/CSS 로 직접 그리는 편이 나은 아이콘·도형·도표
- 한 번 보고 버릴 미리보기 → Codex 기본 `imagegen` 으로 충분
- Codex 가 없는 환경(Claude 앱·ChatGPT 웹만 쓰는 경우) → 이 스킬은 `codex` 명령을 부른다

## 준비물 (하나라도 없으면 먼저 알려 주고 멈춘다)

1. `codex --version` 이 동작하고 로그인돼 있다 (내장 `image_gen` 은 API 키 없이 로그인 세션으로 돈다)
2. `python3` 와 Pillow 패키지 (`python3 -c "import PIL"` 이 에러 없이 끝나야 한다)
3. Node.js 18 이상

## 절차

1. 슬롯이 이미 만들어져 있는지 먼저 본다. 승인된 그림은 덮어쓰지 않는다 (스크립트도 기본 거부).
2. 무엇을 만드는지 고른다.
   - 그림 한 장: `node scripts/gen-image.mjs <출력.png> "<설명>" [옵션]`
   - 애니메이션 세트: `node scripts/gen-frames.mjs <폴더> "<캐릭터 설명>" <동작> [프레임수] [옵션]`
3. 먼저 `--plan` 으로 계획만 출력해 본다 (Codex 를 부르지 않는다). 프롬프트·기준 이미지·호출 횟수를 확인한다.
4. 실행한다. 한 장에 보통 1~3분. 끝나면 `art-raw/` 에 원본이, 출력 경로에 마무리본이, `image-ledger.jsonl` 에 기록이 남는다.
5. **눈으로 확인한다.** 스크립트의 검사는 "깨진 것"을 거르지 "좋은 그림"을 보증하지 않는다. 투명 그림은 어두운 배경과 밝은 배경 양쪽에 올려 가장자리 번짐을 본다. 프레임 세트는 한 장으로 이어 붙여(contact sheet) 본다.
6. 실패한 한 장만 다시 뽑는다. 프레임 세트는 `art-raw/<세트 이름>/frame_NN.png`(원본) 중 **다시 뽑을 장만 지우고** 같은 명령에 `--resume` 을 붙인다 — 없는 원본만 새로 만들고, 마무리(배경 지우기→fit→normalize→audit)는 항상 원본 전체에서 다시 한다. 단일 그림은 `--force`. 세트 전체를 다시 뽑지 않는다.

## 옵션 요약

| 옵션 | 뜻 |
|---|---|
| `--transparent` | 배경을 마젠타 단색으로 받아 알파로 바꾼다 (체커보드 방지) |
| `--ref <이미지>` | 기준 이미지. 여러 번 줄 수 있다. 같은 캐릭터·스타일로 그린다 |
| `--style "…"` | 스타일 한 줄 ("도트 픽셀아트, 제한된 팔레트" 등) |
| `--size WxH` | 마무리 캔버스. 비율 유지, 남는 자리는 투명. 도트면 `--pixel` 같이 |
| `--model`, `--effort` | Codex 에이전트 모델·추론 강도. 안 주면 내 Codex 기본값 |
| `--plan` | 호출 없이 계획만 출력 |
| `--force` / `--resume` | 덮어쓰기(프레임 수를 줄이면 남는 꼬리 프레임도 치움) / 원본이 있는 프레임은 건너뛰고 없는 것만 생성 |

`--model` 은 **그림을 그리는 모델이 아니라 Codex 에이전트 모델**이다. 내장 도구 모드는 그림 모델을 고르는 손잡이를 주지 않는다.

## 지켜야 할 것

- 내장 `image_gen` 만 쓴다. API/CLI 대체 경로(별도 API 키 필요)로 슬쩍 넘어가지 않는다. 필요하면 사용자에게 먼저 묻는다.
- 프롬프트에 사용자가 적은 문구·글자는 **그대로** 옮긴다. 그림 속 글자는 틀리기 쉬우니 맞는지 확인한다.
- 실존 인물·기존 캐릭터·상표를 그리게 하는 요청은 사용자가 권리를 가진 경우에만 진행한다.
- 결과를 보고할 때 저장 경로, 쓴 프롬프트, 호출 횟수, 실패해서 다시 뽑은 장수를 함께 말한다.

막힐 때If you get stuck

codex 명령이 없다고 나오면 터미널의 PATH 를 확인하세요(앱 안 터미널과 일반 터미널이 다를 수 있어요). “배경이 지워지지 않았다”가 나오면 프롬프트에서 배경을 암시하는 말(바닥·그림자)을 줄이고 다시 시도하세요. 실패한 한 장만 다시 뽑는 옵션(--resume, --force)이 있어요. 증상별 해결은 키트 안 references/pitfalls.md 에 있어요. 한 장에 40초~3분 걸리고 Codex 사용량이 차감돼요.
