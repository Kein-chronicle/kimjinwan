Casewright — 근거 있는 테스트 케이스 만들기

요구사항·기획서에서 근거가 붙은 테스트 케이스를 만들고 엑셀 양식으로 내보내요

써 보기Try it

설명About

요구사항 정의서, 기획서, 화면설계서, 사용환경 문서를 올리면 테스트 설계 기법별로 테스트 케이스(TC)를 만들고, 점검 규칙(게이트)으로 걸러서 엑셀로 내보내는 웹 서비스예요. 모든 케이스에는 근거가 된 원문 위치가 붙고, 근거 없이 지어낸 예상 결과는 표시돼요. 추천 양식 4종 중에서 고르거나 내 회사 엑셀 양식을 올려 맞출 수도 있어요. AI 판단은 내 컴퓨터의 Claude Code 또는 Codex를 연결해서 쓰고, 검증과 파일 생성은 서버가 해요.

이런 분께 맞습니다Who it is for

QA·테스트 담당자, 기획서를 보고 테스트 케이스를 정리해야 하는 개발자·기획자.

결과물What you get

근거가 연결된 테스트 케이스 목록과 요구사항 추적표(RTM), 엑셀 파일(.xlsx).

쓰는 방법How to use

  1. [써 보기]를 눌러 새 창에서 열고 로그인해요.
  2. 앱 안의 연결 안내에 따라 내 컴퓨터의 Claude Code 또는 Codex를 연결해요.
  3. 요구사항·기획서 등 자료를 올리고 테스트 조건과 위험 항목을 확인해요.
  4. 케이스 설계와 작성 결과를 점검 규칙으로 확인한 뒤 추천 양식 또는 내 양식으로 엑셀을 내려받아요.

막힐 때If you get stuck

로그인(이메일·Google·Apple)이 필요해요. AI 기능은 내 컴퓨터에 Claude Code 또는 Codex가 이미 설치되어 있고, 앱 안의 연결 안내에 따라 연결 프로그램(Agent)을 실행해 코드로 이어야 해요. 자료를 올리면 내용이 내 PC의 연결 프로그램을 거쳐 내 계정의 AI 제공자(Anthropic·OpenAI)로 전달되니, 개인정보나 기밀이 든 자료는 신중하게 다뤄 주세요. AI 결과는 틀릴 수 있어요. 숫자·근거는 꼭 원문과 대조해 확인해 주세요. 예상 결과가 근거 없이 만들어진 케이스는 "근거 없음"으로 표시돼요. 그대로 쓰기 전에 사람이 확인해 주세요.
