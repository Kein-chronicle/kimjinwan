글쓰기Writing

DocLoom — 브라우저 문서 편집기

txt·md·docx·hwp·hwpx·puml 문서를 포맷별 전용 편집기로 만들고 고쳐요. 내 PC의 AI를 연결할 수도 있어요

써 보기Try it

설명About

설치도 가입도 없이 브라우저에서 여는 문서 편집기예요. TXT, MD(마크다운), DOCX, HWP, HWPX, PUML(PlantUML 다이어그램)을 포맷마다 전용 편집 화면으로 새로 만들고, 열고, 고쳐서 같은 형식으로 저장해요. 문서는 서버로 전송되지 않고 이 브라우저에만 저장돼요(로컬 저장 전용). 로그인 기능은 없어요. "AI 연결"을 켜면 내 컴퓨터에 설치한 연결 프로그램(docloom-agent)으로 내 PC의 Claude Code나 Codex를 연결해서 문서 작성·수정·요약·서식·다이어그램 제안을 받을 수 있고, AI의 모든 수정은 미리보기를 본 뒤 [적용]을 눌러야 반영돼요. DocLoom은 한컴·Microsoft와 제휴 관계가 없는 독립 서비스예요.

이런 분께 맞습니다Who it is for

메모, 보고서, 한글 문서, 마크다운, 다이어그램을 설치 없이 한곳에서 다루고 싶은 분. 이미 Claude Code나 Codex를 쓰고 있어서 문서 작업에도 연결해 보고 싶은 분.

결과물What you get

편집한 문서를 .txt, .md, .docx, .hwp, .hwpx 파일로 내려받을 수 있고, 다이어그램은 PNG·SVG로 내보낼 수 있어요. AI가 제안한 수정은 미리보기에서 확인한 뒤에만 적용되고, 적용한 변경은 되돌릴 수 있어요.

쓰는 방법How to use

  1. [써 보기]를 눌러 새 창에서 열어요. 로그인이나 설치 없이 바로 쓸 수 있어요.
  2. 홈의 "새 문서" 카드에서 만들 포맷을 고르거나, 가진 파일을 "파일 열기"로 불러와요. 입력하는 내용은 이 브라우저에 자동 저장돼요.
  3. 끝나면 Ctrl+S(맥은 Cmd+S)로 같은 형식의 파일로 저장해요. 다른 컴퓨터에서 이어서 하려면 파일로 저장하거나 전체 백업(zip)을 쓰세요.
  4. AI를 쓰고 싶다면 앱 안의 "AI 연결" 안내를 따라 해요. 내 컴퓨터에 Claude Code 또는 Codex가 이미 설치되어 있어야 하고, 안내에 나오는 연결 프로그램(docloom-agent)을 설치·실행한 뒤 코드로 연결하는 방식이에요. AI가 제안한 수정은 미리보기를 확인하고 [적용]을 눌러야 반영돼요.

막힐 때If you get stuck

문서는 이 브라우저에만 저장돼요. 브라우저의 "사이트 데이터 삭제"나 시크릿 창 종료는 문서를 지우니, 정기적으로 파일로 저장하거나 전체 백업을 받아 두세요. DOCX·HWP·HWPX는 저장 후 Word나 한글에서 한 번 열어 확인하세요. 원본 프로그램과 모든 부분이 똑같이 열린다고 보장하지는 않아요. AI 기능은 내 컴퓨터의 AI 도구와 연결 프로그램이 있어야 해요. AI에게 부탁하면 문서 내용이 내 PC의 연결 프로그램을 거쳐 내 계정의 AI 제공자(Anthropic·OpenAI)로 전달되니, 민감한 문서는 신중하게 다뤄 주세요.
