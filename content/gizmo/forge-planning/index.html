창작Creative

Forge — 요구사항에서 기획서·목업까지

요구사항을 넣으면 정의서, 디자인 가이드, 핵심 화면, 목업 사이트, 기획서까지 단계별로 만들어 줘요

써 보기Try it

설명About

요구사항 한 덩어리를 받아 요구사항 정의서 → 디자인 가이드 → 핵심 화면 → 전체 목업 사이트 → 기획서 순서로 만들어 주는 웹 서비스예요. 단계마다 결과를 보고 고쳐서 다음으로 넘어가는 방식이라, 한 번에 통째로 만들고 끝나는 도구가 아니에요. AI 판단은 내 컴퓨터에 설치한 Claude Code 또는 Codex를 연결해서 쓰고, 단계 진행과 파일 정리는 서버가 맡아요. 기즈모 스토어도 이 방식으로 기획했어요. (개발 산출물 단계는 아직 준비 중이에요.)

이런 분께 맞습니다Who it is for

앱·서비스 아이디어를 기획서와 화면 시안으로 먼저 정리하고 싶은 분, 이미 Claude Code나 Codex를 쓰고 있어서 기획 작업에도 연결해 보고 싶은 분.

결과물What you get

요구사항 정의서, 디자인 가이드, 핵심 화면 설계, 클릭해 볼 수 있는 목업 사이트, 기획서가 단계별 산출물로 쌓여요.

쓰는 방법How to use

  1. [써 보기]를 눌러 새 창에서 열고 로그인해요.
  2. 앱 안의 연결 안내에 따라 내 컴퓨터의 Claude Code 또는 Codex를 연결해요.
  3. 새 프로젝트를 만들고 요구사항을 적거나 문서를 올려요.
  4. 단계마다 나온 결과를 읽고 고칠 곳을 알려 준 뒤 다음 단계로 넘어가요.

막힐 때If you get stuck

로그인(이메일·Google·Apple)이 필요해요. AI 기능은 내 컴퓨터에 Claude Code 또는 Codex가 이미 설치되어 있고, 앱 안의 연결 안내에 따라 연결 프로그램(Agent)을 실행해 코드로 이어야 해요. 자료를 올리면 내용이 내 PC의 연결 프로그램을 거쳐 내 계정의 AI 제공자(Anthropic·OpenAI)로 전달되니, 개인정보나 기밀이 든 자료는 신중하게 다뤄 주세요. AI 결과는 틀릴 수 있어요. 숫자·근거는 꼭 원문과 대조해 확인해 주세요.
