AI 게임 개발기: 브라우저에서는 됐는데 실행 파일에서는 멈췄다

기록일 2026. 5. 16.수정 2026. 9. 9.

표시 날짜는 이 글이 다루는 작업의 대표 기록일이며, 당시 발행된 글을 뜻하지 않습니다. 이후 회고와 적용 방법은 2026년 9월에 정리했습니다.

이 글의 목적

Electron 등으로 웹게임을 실행 파일로 패키징하려는 개발자에게, 웹 서버 기준 자산 경로와 파일 기반 실행 경로가 다르다는 걸 웨일서바이버의 Windows 멈춤 수정 사례로 보여준다.

핵심 내용

5월 16일에는 데모 전용 빌드를 따로 준비해 제작 중 쓰던 무기 즉시 지급·즉시 성장 같은 개발용 기능을 사용자 버전에서 뺐다 — 출력 폴더와 패키징 설정도 별도로 나눴다.

읽고 나서

패키징한 실행 파일을 열기 전에 개발 서버와 캐시를 모두 끄고, 새 출력 폴더의 실행 파일만으로 로비·전투 이미지가 뜨는지 확인한다.

먼저 답하면

5월 19일 QA 보고서는 Windows 실기 확인을 ‘남은 항목’으로 분리해뒀다. 이미지 경로와 실행 멈춤을 고친 커밋은 있었지만, 목표 기기에서 확인을 마쳤다는 기록은 아니었다.

5월 초에는 로비와 스토리 장면을 손보면서 Windows 실행 문제도 같이 고쳤다. 화면에 넣을 것이 많아지는 와중에, 브라우저 밖으로 꺼낸 게임은 다른 이유로 멈췄다.

대표적인 차이는 이미지 경로였다. 웹 서버의 루트에서 찾던 파일을 Electron의 파일 기반 실행에서도 같은 방식으로 찾을 수는 없었다. 자산 경로를 상대 경로로 바꾼 뒤 Windows 이미지와 실행 멈춤을 고치는 변경이 이어졌다.

실행 파일을 만들고 나서도 남은 일

5월 16일에는 데모용 빌드를 따로 준비했다. 개발 중 편하게 쓰던 무기 지급이나 즉시 성장 기능은 사용자에게 전달할 버전에서는 빠져야 했다. 출력 폴더와 패키징 설정도 구분했다.

이때의 문제는 새 기능 하나를 잘못 만든 것과 조금 달랐다. 같은 코드라도 어디서 실행하느냐에 따라 자산을 찾는 방식과 설정이 달라졌다. 브라우저 테스트만 반복하면 놓칠 수 있는 부분이었다.

5월 15일 보존된 화면. 목표와 진화 경로, 태그 효과가 함께 보인다. Windows 오류 수정 전후 비교 화면은 아니다.

화면만 보면 이미 여러 시스템이 들어가 있다. 수정 커밋이 쌓였다고 해서 그 목록이 곧 확인을 마쳤다는 뜻은 아니었다.

이 구간은 스팀 출시 성공담보다는 데모를 준비하며 배포 환경을 다룬 기록이다. 실제 데모 공개나 판매 결과는 여기서 확인한 범위에 없다.

다시 시작한다면 작은 상태에서 실행 파일부터 자주 만들어볼 생각이다. 콘텐츠를 잔뜩 넣은 뒤 멈추면 의심할 곳도 많아진다. 마지막에 패키징 버튼을 누르는 것만 배포 준비가 아니라는 점이 남았다.
