앱 제작·심사Apps · 2026-09-14

One Thing Today: Daily Goal — 하루에 목표 하나만 남기는 위젯 앱

발행 2026. 9. 14.수정 2026. 9. 23.
이 글의 목적

할 일 목록이 자꾸 쌓이는 독자에게 하나만 남기는 접근 방식을 보여주고, 실제 다운로드 가능 여부까지 확인하게 한다.

핵심 내용

40개의 실용적인 목표 템플릿 중 고르거나 직접 한 줄을 적어 그날의 목표를 하나만 남긴다. 교체할 때 밀린 목록이 쌓이지 않고, 홈·잠금 화면 위젯에서 완료 처리와 알림을 하나만 설정한다. 연속 기록이 끊겨도 실패 표시나 순위 없이 완료한 날만 세는 주간 리뷰가 특징이다. 2026년 9월 11일 제출한 버전 1.1이 9월 19일 기준 반려됐다가, 9월 23일 확인 결과 같은 버전이 App Store Connect에서 판매 중(READY_FOR_SALE) 상태로 바뀌었고 공개 iTunes 조회로도 실제 등록을 확인했다.

읽고 나서

실제 다운로드 후 위젯·주간 리뷰 동작을 확인하고, 국가별 노출 차이가 있는지 다음 확인에서 본다.

One Thing Today가 필요한 상황

할 일 목록 앱은 대부분 쓸수록 항목이 늘어난다. 이 앱은 그 반대를 택해, 하루에 정확히 하나의 목표만 남기는 방식으로 만들어졌다.

실제로 할 수 있는 일

40개의 실용적인 목표 템플릿 중 고르거나 직접 짧은 문장으로 적는다. 목표를 바꿔도 이전 목표가 밀린 목록으로 쌓이지 않고, 그날엔 항상 활성 목표가 하나만 존재한다. 홈 화면 소형·중형 위젯과 잠금 화면 위젯이 같은 기록을 읽어 위젯에서 바로 완료 처리를 할 수 있고, 원하는 시간에 알림을 하나만 걸 수 있다(알림 문구에는 목표 내용이 드러나지 않는다). 완료 후 짧은 소감을 남길 수 있고, 주간 리뷰는 실패 표시·페널티·순위 없이 완료한 날수만 센다. 완료 카드를 내보내 공유할 수 있고, 보상형 광고는 꾸밈 효과만 잠금 해제할 뿐 목표 설정이나 위젯, 기록 자체를 막지 않는다.

다운로드와 제공 상태

2026년 9월 14일 App Store Connect에서 확인한 상태는 심사 대기 중이었고, 9월 19일 기준으로는 반려였다. 2026년 9월 23일 다시 확인하니 같은 버전 1.1이 다운로드 가능(READY_FOR_SALE) 상태였고, 공개 iTunes 조회(itunes.apple.com/lookup)에서도 실제 등록을 확인했다. 개인 팀에 등록된 앱이며, 국가별 판매 가능 여부나 실제 서버 동작까지 전부 검증했다는 뜻은 아니다.

사용 전에 알아둘 점

이 글은 앱 제작 단계에서 정리한 스토어 설명 자료를 근거로 썼으며, 실제 사용 후기가 아니다. 심사 대기와 제출 준비를 출시 완료로 바꾸어 적지 않았다.
