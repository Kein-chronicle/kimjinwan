사진 여러 장 합치기 — 가로·세로·격자 콜라주

발행 2026. 9. 10.
이 글의 목적

전후 비교, 영수증 묶음, 작업 과정을 공유하기 쉬운 한 장의 이미지로 만든다.

핵심 내용

사진 순서와 잘리는 영역을 미리 확인하고 작은 글자가 있다면 충분한 출력 크기를 선택한다.

읽고 나서

사진을 순서대로 추가하고 배치, 간격, 배경색을 정한다.

목차
  • 배치 선택
  • 잘림과 해상도

배치 선택

가로형은 전후 비교, 세로형은 긴 기록, 격자형은 여러 항목을 같은 크기로 보여줄 때 편하다. 입력한 순서대로 왼쪽 위에서 배치된다.

사진 여러 장 합치기 열기

잘림과 해상도

칸을 일정하게 맞추기 위해 사진 가장자리가 일부 잘릴 수 있다. 영수증이나 문서처럼 가장자리 정보가 중요한 사진은 결과 미리보기를 확대해서 확인한다. 모든 처리는 브라우저 안에서 이뤄진다.

같이 읽을 글

  • 이미지 자르기·회전 — 정사각형과 16:9 비율 맞추기

    사진을 원본 비율에 맞춰 자르고 90도 단위로 회전해 새 이미지로 저장하는 방법이다.

  • 이미지 워터마크 넣기 — 사진에 출처 문구 표시

    사진에 문구·위치·크기·투명도를 정해 워터마크를 넣는 방법과 보호 범위를 설명한다.

  • JSON 포매터·검증기 — 큰 숫자는 그대로 두고 공백만 정리하기

    API 응답과 설정 JSON을 2칸·4칸 또는 한 줄로 정리한다. 큰 정수와 숫자 표기를 보존하는 방식, 중복 키 오류, 문법 검사와 데이터 검증의 차이를 설명한다.
