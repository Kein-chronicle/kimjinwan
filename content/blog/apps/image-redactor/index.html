이 글의 목적

눈에 보이는 개인정보를 필요한 영역만 가려 안전하게 공유하게 한다.

핵심 내용

식별 정보보다 넓게 가리고 저장 결과를 확대해 다시 확인한다.

읽고 나서

사진에서 가릴 영역을 드래그하고 결과 PNG를 확대 확인한다.

무엇을 가릴까

얼굴, 이름, 주소, 차량 번호와 화면 알림처럼 사람을 특정할 수 있는 정보를 확인한다.

이미지 모자이크·가리기 열기

한계

이미지 픽셀만 바꾼다. PDF 숨은 텍스트나 원본 파일 기록을 지우는 도구는 아니다.

같이 읽을 글

  • 사진 메타데이터 제거 — GPS·EXIF 없이 공유하기

    사진 픽셀만 새 파일로 저장해 위치·촬영 기기 등 EXIF 정보를 제거하는 방법이다.

  • JSON 포매터·검증기 — 큰 숫자는 그대로 두고 공백만 정리하기

    API 응답과 설정 JSON을 2칸·4칸 또는 한 줄로 정리한다. 큰 정수와 숫자 표기를 보존하는 방식, 중복 키 오류, 문법 검사와 데이터 검증의 차이를 설명한다.

  • 중복 줄 제거기 — 공백 무시를 켜도 원문이 그대로 남는 이유

    한 줄씩 입력한 목록에서 중복을 정리하고 첫 등장 순서와 원문 줄 번호를 확인한다. 공백·대소문자 비교 옵션이 결과를 바꾸는 범위와 빈 줄 처리의 차이를 설명한다.
