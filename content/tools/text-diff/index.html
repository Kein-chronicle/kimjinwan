텍스트 비교기

도구 열기Open the tool

수정 전후 문서를 붙여 넣어 추가·삭제·유지된 줄과 줄 번호를 즉시 비교합니다.

수정 전후 문서를 붙여 넣으면 추가·삭제된 줄이 바로 표시됩니다. 원본은 서버로 전송되거나 저장되지 않습니다.

쓰는 방법How to use

  1. 화면의 항목(수정 전 텍스트, 수정 후 텍스트)을 채우거나 고릅니다.
  2. 필요하면 버튼(모두 비우기, 결과 복사)을 눌러 결과를 가져갑니다.

알아두면 좋은 점Good to know

각 입력 최대 100,000자 · 500줄. 줄바꿈 형식(CRLF/LF)은 동일하게 취급합니다.

앞 숫자는 수정 전, 뒤 숫자는 수정 후 줄 번호입니다. + 추가 / − 삭제 / = 유지. 공백 무시 시 유지 줄은 수정 전 원본을 표시합니다.

어떤 차이를 보여주나요?

공지, 이메일 초안, 번역문, 설정 파일의 두 버전을 줄 단위로 대조합니다. 예시에서는 회의 일정 1줄이 삭제·추가로 바뀌고, 온라인 참석 안내 1줄이 새로 추가됩니다. 수정한 줄은 삭제 1줄과 추가 1줄로 세며, 줄 이동도 삭제와 추가로 표시할 수 있습니다.

비교 원리와 공백 옵션

두 문서에서 순서를 유지하며 공통으로 나타나는 줄을 가장 많이 찾는 최장 공통 부분 수열(LCS) 방식입니다. 같은 줄이 반복되면 여러 정렬이 가능하며 이 도구는 삭제를 먼저 표시합니다. 공백 무시는 각 줄의 스페이스와 탭을 모두 제외하므로 “서울 역”과 “서울역”도 같아집니다. 의미 있는 공백이 있는 코드나 문장은 이 옵션을 끄고 확인하세요.

결과 해석과 한계

글자별 강조나 문서 서식·이미지 비교, 표절·의미 판정은 제공하지 않습니다. 대소문자와 유니코드 구성 차이는 유지합니다. 마지막 줄바꿈은 빈 줄로 비교됩니다. 워드·PDF 파일은 텍스트를 직접 복사해 넣고, 긴 문서는 구간을 나눠 비교하세요. 두 입력이 비어 있으면 0줄이며, 결과 복사는 +와 -가 붙은 참고용 텍스트로 패치 파일이 아닙니다.
