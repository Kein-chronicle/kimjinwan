PDF 페이지 정리

도구 열기Open the tool

페이지 순서를 바꾸거나 필요한 페이지만 새 PDF로 추출합니다.

페이지 번호 순서를 입력해 재정렬하거나 필요한 페이지만 새 PDF로 추출합니다.

쓰는 방법How to use

  1. 화면의 항목(PDF 선택, 새 페이지 순서)을 채우거나 고릅니다.
  2. 필요하면 버튼(새 PDF 만들기)을 눌러 결과를 가져갑니다.

알아두면 좋은 점Good to know

예: 3, 1, 2는 3페이지를 맨 앞으로 옮깁니다. 1, 3은 2페이지를 제외합니다.

이렇게 사용하세요

PDF를 한 개 고르면 원본 페이지 수가 표시되고 새 페이지 순서 칸에 1부터 끝 페이지까지 번호가 채워집니다.

번호를 쉼표로 구분해 원하는 순서로 고쳐 씁니다. 지운 번호의 페이지는 결과에서 빠집니다.

결과 페이지 수를 확인하고 새 PDF 만들기를 누른 뒤 정리된 PDF 다운로드로 organized.pdf를 저장합니다.

번호는 1 이상 전체 페이지 수 이하의 정수만 쓸 수 있고 3-5 같은 범위 표기는 지원하지 않으므로 3, 4, 5처럼 하나씩 적어야 합니다. 형식이 맞지 않으면 안내 문구가 나타나고 파일은 만들어지지 않습니다.

재정렬과 추출

입력한 번호만 그 순서대로 복사합니다. 같은 페이지 번호를 두 번 쓰면 결과에도 두 번 들어갑니다.

암호가 걸린 PDF는 처리하지 않습니다. 전자서명과 양식 필드는 페이지 복사 과정에서 원본과 다르게 동작할 수 있으니 결과를 확인하세요.
